# ✦ بالمِرصاد | BALMIRSAD AI Command Center 3.0

تطبيق **Streamlit** متكامل لعرض قوة Python في لوحات التحكم: **عربي/English، Dark/Light، تحليلات تفاعلية، محاكاة توزيع فرق، ومساعد ذكي**.

> **Demo only:** 286 synthetic incidents. Not actual municipal, satellite, or AI detection data. Risk priority is an illustrative calculation, **not a trained machine-learning model**.

## 1 — التشغيل باستخدام VS Code (Windows)

افتح مجلد `balmirsad_streamlit` في VS Code ثم شغل Terminal:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

أو إن كانت المكتبات مثبّتة بالفعل:

```powershell
streamlit run app.py
```

افتح `http://localhost:8501` عند الحاجة.

## 2 — Language + Theme

أعلى الشريط الجانبي ستجد `Language / اللغة` للتبديل بين العربية والإنجليزية، و`Theme / المظهر` للتبديل بين Dark وLight. تتغير تسمية الرسوم والفلاتر وواجهة المساعد بحسب اللغة، وتتغير لوحة الألوان والرسوم بحسب المظهر المختار.

## 3 — Mirsad AI Copilot

من **كل صفحة** اضغط الزر العائم **✦ اسأل المرصاد AI** أسفل يسار الشاشة لفتح نافذة الشات. يمكنك كتابة أي سؤال والضغط على إرسال، واستمرار المحادثة مع حفظ رسائل الجلسة. يوجد وضعان:

### Instant insights — جاهز فورًا، لا يتطلب نموذج AI

- ملخص لحظي حسب الفلاتر الفعالة.
- أعلى الأحياء والبلاغات خطورة.
- اقتراحات توزيع بناءً على قواعد واضحة.
- هذا الوضع **rule-based**، وليس ذكاءً اصطناعيًا توليديًا.

### Local AI (Ollama) — نموذج ذكاء اصطناعي حقيقي يعمل محليًا

ثبت [Ollama](https://ollama.com/download) أولًا، ونزّل نموذجًا أثناء توفر الإنترنت:

```powershell
ollama pull qwen2.5:3b
```

ثم تأكد أن خدمة Ollama تعمل (يمكن تشغيل `ollama serve` إذا لم تعمل تلقائيًا)، واضغط زر الشات العائم داخل Streamlit، واختر **Ollama AI**، واكتب `qwen2.5:3b` في اسم النموذج. يمكنك تجربة `qwen2.5:7b` إذا كان جهازك قادرًا على تشغيل نموذج أكبر.

- يرسل التطبيق إلى خادم Ollama المحلي `127.0.0.1:11434` **ملخصات وإحصاءات بيانات الديمو المفلترة** وأحدث سياق محادثة.
- لا يطلب OpenAI API key، ولا يستخدم Cloud API في هذا الوضع.
- بعد تنزيل الحزم والنموذج مرة واحدة، يمكن استخدام Streamlit وOllama دون اتصال بالإنترنت.
- لو كان نموذج Ollama غير متاح، يُظهر التطبيق تنبيهًا ثم يستخدم تحليلًا مباشرًا قائمًا على القواعد بدلًا من ادعاء أنه AI.
- على جهاز شركة أو بيانات حقيقية، راجع سياسات الأمن وحماية البيانات قبل ربط نماذج أو خدمات، وأضف نظام مصادقة وصلاحيات قبل النشر متعدد المستخدمين.

## 4 — الصفحات

1. **Command Center:** مؤشرات تشغيلية، مخطط مكاني تفاعلي، وتنبيهات ذات أولوية.
2. **Incident Explorer:** تفاصيل البلاغ، تفسير عوامل المخاطر، وتغيير الحالة والفريق في الجلسة فقط.
3. **Analytics Studio:** اتجاهات، تحليلات حي × نوع المخلفات، متوسط زمن الاستجابة، وتصدير CSV.
4. **Decision Lab:** تعديل أوزان المخاطر، محاكاة السعة، وتوليد خطة فرق قابلة للتصدير.
**Floating Mirsad AI:** الشات عائم في جميع الصفحات، وليس صفحة مستقلة. الردود التوليدية متاحة عند تشغيل Ollama.

## 5 — تجربة الشات والتصميم

- الشات عائم أسفل يسار الشاشة، ويُفتح بالنقر على زر **✦ اسأل المرصاد AI**.
- اختر **Ollama AI** لمحادثة لغوية فعلية متصلة بملخص البيانات المفلترة. هذا الوضع يحتاج تنزيل النموذج مسبقًا.
- اختر **تحليل مباشر** للحصول على إجابات حسابية مبنية على البيانات بدون نموذج لغوي.
- أضفنا حركات دخول، تأثيرات Hover، وحالة بث نابضة خفيفة، مع دعم `prefers-reduced-motion`.
- حسّنا قيود عرض الأعمدة والرسوم والبطاقات لتخفيف التداخل على أحجام الشاشات المختلفة.
- الشات يتم عبر `st.popover` وليس نافذة HTML وهمية، ولهذا يمكنه استخدام حالة Streamlit والتعامل مع كود Python فعليًا.

## 6 — تشغيل دون إنترنت

بعد التثبيت الأولي للـPython packages وOllama والنموذج، التطبيق لا يحتاج اتصال إنترنت. بياناته مولدة في الذاكرة، والمخطط المكاني لا يستخدم map tile services. هناك استيراد اختياري لخطوط Google في CSS؛ عند انقطاع الإنترنت يستخدم المتصفح خطوط النظام تلقائيًا. لا توجد قاعدة بيانات حقيقية متصلة.

## 7 — ملاحظات التصميم والخصوصية

- اللغة الافتراضية العربية، والثيم الافتراضي Dark.
- البيانات لا تحفظ في قاعدة بيانات؛ تحديثات البلاغات والمحادثة مؤقتة في Session State.
- النموذج المحلي قد يعطي تفسيرات غير دقيقة؛ لهذا السياق يذكر صراحة أن المعلومات تجريبية ويمنع اختلاق الأرقام في التعليمات.
- لا يشمل المنتج الحالي تسجيل دخول المستخدمين أو RBAC أو تسجيل تدقيق؛ هذه مكونات مطلوبة قبل النشر الفعلي.
